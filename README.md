## 线路实际怎么走？

官方口径是香港机房支持 CN2 线路。第三方测评的实测记录显示得更具体：回程电信走香港 FPT 再经 CTG（即 CN2 网络），联通绕美，移动走香港 NTT；去程电信绕欧，联通走香港 NTT，移动走新加坡。
